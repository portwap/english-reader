# english-reader

A small site for learning English by reading and listening.

Paste a short English text into the admin form, and the site builds a page for it:

- the whole text read aloud by a natural voice, with the current word highlighted;
- play one sentence, or click a word to hear just that word;
- a Russian translation of each sentence, done with the whole text as context.

The full plan is in [docs/PLAN.md](docs/PLAN.md).
